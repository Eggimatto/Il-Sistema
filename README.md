# IL SISTEMA — Risveglio

PWA mobile-first per il monitoraggio personale di sonno, attività, umore, abitudini e obiettivi con quest, dungeon e progressione RPG.

**Privacy:** il repository contiene solo codice statico e asset grafici. I dati del diario restano sul dispositivo; il cloud personale è facoltativo e non ancora attivo. Nessun dato personale o chiave privata deve essere caricato su GitHub.

**Stato:** pubblicazione statica in corso. Per le istruzioni di installazione consulta la sezione Report e archivio dell'app.

La sincronizzazione cloud richiede un progetto Supabase dedicato, configurato nell'app tramite URL e chiave **pubblicabile**. Non inserire mai una chiave segreta nel frontend.
